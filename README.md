# Estruturas de Repetição em Java: `while` e `do-while`

Este repositório contém exemplos e explicações sobre o uso dos laços de repetição `while` e `do-while` na linguagem Java. Ambos são utilizados para repetir trechos de código com base em condições lógicas, sendo ideais para situações onde o número exato de repetições é desconhecido.

---

## 🚀 Como Funcionam?



### 1. `while` (Pré-testado)
Avalia a condição antes de executar o bloco. Se a condição for falsa na primeira tentativa, o código dentro dele é completamente ignorado.

```java
while (condição) {
    // Código executado apenas se a condição for verdadeira
}
